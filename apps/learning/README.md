# Learning

A daily nudge to keep learning. Learning sends you one GRE vocabulary word per day over Telegram — small, consistent, and easy to keep up with.

## What you get

- One curated GRE vocabulary word delivered every day
- Sent straight to you on Telegram, where you already check messages
- A low-friction daily habit that adds up over weeks and months

## When to use it

Turn this on if you're prepping for the GRE, brushing up on advanced English vocabulary, or just want a tiny daily learning ritual that doesn't require opening yet another app.
