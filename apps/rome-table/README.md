# RomeTable

A simple, no-frills browser for the data inside your Rome workspace. Open it up to see what's stored, what each app is writing, and what's actually in your tables.

## What you get

- Browse every table from your installed apps in one place
- Inspect rows, columns, and the data each app has collected
- Filter and search to find what you're looking for
- A clean, read-friendly view — no SQL required

## When to use it

Use RomeTable when you want to peek behind the curtain — checking that an app is actually capturing what you expected, debugging a weird result, or just exploring what's in your workspace. Think of it as the "open the filing cabinet and look around" tool.
