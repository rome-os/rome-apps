# TikHub

用一个 TikHub API Key 查询抖音、TikTok、小红书、B 站、快手、微博、知乎、Instagram、YouTube、X 等平台的公开数据。可让 Agent 查找接口并总结结果，也可在页面查看合同、报价和调用记录。

## 功能与安全边界

- **接口发现**：按平台和关键词搜索公开 OpenAPI；参数与基准单价来自 TikHub，目录按需刷新，通常缓存 24 小时。
- **公开读取**：仅发送当前合同中支持的公开 GET/POST 读取。只允许本地冻结策略中的端点；目录刷新不会自动开放新端点。未知方法/路径、过期合同、私有凭据、登录/设备注册/账号变更和弃用端点均拒绝。`confirm: true` 不能解锁这些能力。
- **身份隔离**：HTTP 仅允许 guardian；Action 还要求宿主可信身份，不接受访客、群聊或没有身份归属的自主任务。宿主或自动委派链若不能提供可信 actor，会拒绝 Action，不会降低为匿名执行；不编造仅凭版本号即可判断的最低 Core 门槛。
- **先预览**：预览仅验证并构造脱敏请求，不发送数据请求。输入验证有明确支持范围；不支持的约束会拒绝，不承诺兼容任意未来 OpenAPI。
- **不盲目重发**：账户和数据请求至多发送一次；超时、网络错误或响应丢失后标记结果/费用未知，需要先核对用量。仅固定公开目录/价格/健康 GET 可安全重试。
- **有界处理**：输入最多 64 KiB，响应最多读取 8 MiB；日志只保留脱敏、裁剪的预览，不是完整响应备份。应用 DB 协调 Agent 与页面请求槽，并考虑端点限速；长队列会拒绝。
- **调用记录与估算**：记录数据调用及本地拦截；目录、余额、健康和每日用量查询不在此账本中。未知费用单列，不能当作 $0；余额/usage 与本地记录的范围不同。

## 价格与地址

默认使用 **https://api.tikhub.io**。`https://api.tikhub.dev` 仅作为旧兼容地址保留，官方不再推荐；不支持其他子域、端口或自定义服务器。[官方说明](https://docs.tikhub.io/)

不要把 $0.001–$0.01 当作价格上限：2026-11-13 的公开价表中，部分批量高清解析端点已为 **$0.25/次**。每次先查看当前端点报价；基准单价不含账户的日阶梯折扣，也不是最终结算。没有有效最新报价时不发送数据请求。[价格元数据](https://api.tikhub.io/api/v1/tikhub/user/get_all_endpoints_info)、[阶梯定价](https://tikhub.io/pricing)

单条 Douyin/TikTok 分享链接解析目前基准约 $0.001；它是付费数据调用，不是免费预览。余额和每日使用情况的当前合同价为 $0，但仍需使用自己的有效 Key。

## 凭据与日志

Key 继续由原应用设置机制托管（本机应用数据库明文存储），本版没有迁移或重置现有认证材料。设置读口仅返回掩码；请求/响应与预览执行脱敏。上游错误正文不回传、不保存，仅保留状态和结构化错误；本地拦截不保存输入参数。不要把登录 Cookie、密码、代理账号或其他私有会话材料传给 Agent；这版不支持这些操作。

历史记录只在读取时进行安全投影；无法安全解析的旧文本预览会隐藏，不会自动清理或改写原数据。主机/备份失陷的明文存储风险不因输出脱敏而消失。

## 费用授权

调用前按当前价格取得用户对具体接口、数量和预计预算的明确授权；不能从“少量调用”或任何次数阈值推导消费额度。超过范围先询问；结果未知先核对用量，不静默重发。代码的公开读取守卫不是自动支出许可。

## 兼容与验证范围

- 页面要求已登录的 Rome guardian；设置只保留在各自安装实例中。
- Agent Action 需要宿主提供可信 guardian actor；存在 channelContext 时必须是 private，若带 senderBondLevel 还必须为 guardian。调用参数不能补造身份。自动委派若丢失 actor 则不支持并安全拒绝，不得用 loopback 绕过。
- 本地 0.1.3 已完成页面、既有配置、免费账户查询与修复验收；此前直接 guardian Action 有成功验证。当前迁入的 0.1.4 仅做离线回归/构建，不把旧版本结果冒充当前候选全链验收。
- 当前委派宿主的可信 actor 缺失是已知限制，未在本 App 中放宽守卫；PR 不包含 Core 补丁，也不要求部署 Core 才能使用页面。
- 输入/输出及故障回归使用纯合成数据。离线测试不证明所有 Provider、付费结算或任意未来合同可用。

## 开发与测试

在 Rome Apps 仓库根目录安装 workspace 依赖后：

    pnpm --filter @rome/app-tikhub typecheck
    pnpm --filter @rome/app-tikhub test
    pnpm --filter @rome/app-tikhub build

测试由 Vitest 入口运行独立 Node 回归子进程，使用临时 HOME、内存/临时 SQLite 和 synthetic 合同；默认阻断外网 fetch，仅已有重定向 fixture 允许专用本机随机端口。无 Key、无需真实账号、不消费 Provider 额度。
