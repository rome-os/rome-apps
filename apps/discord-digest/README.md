# Discord Digest

Keep up with busy Discord channels without scrolling through every message. Discord Digest reads recent channel history, summarizes it, and posts the digest back into the channel on a schedule you choose.

## What you get

- Scheduled summaries that condense channel activity into a quick-read digest
- Digests posted right back into the channel, so the whole team sees them
- Coverage of links, files, and PDFs shared in the conversation
- One-off digests on demand whenever you want a catch-up
- A history of past digests you can browse and revisit

## Link handling

Discord Digest does not blindly open every link. Each run first builds a compact link index from the channel history, including URL, domain, repeat count, and relevance signals without repeating surrounding message text. The summarizer can then inspect important links progressively: metadata first, then readable excerpts for public HTML/text/PDF pages only when the link is central to the digest.

## When to use it

Use Discord Digest on channels you care about but can't read every day — community servers, internal team rooms, support channels, or noisy announcement feeds. Set it once and check the digest instead of the backlog.
