# Summary

A work summary that writes itself. Summary pulls together your chats, channel messages, and GitHub activity over any time window, then turns it into a clean report organized by project.

## What you get

- One-click reports covering a day, week, or any custom window
- Conversations, team messages, and code activity all woven into the same story
- Output organized by project, so it reads like a status update instead of a log dump
- Optional delivery straight to WeChat when it's ready
- Ask follow-up questions about your own activity, and get answers grounded in the data

## When to use it

Use Summary for weekly reviews, end-of-sprint write-ups, manager updates, or your own personal "what did I actually do this week" check-in. Instead of trawling through Slack, GitHub, and your chat history, you get a finished report in one shot.
