# Memory

Give your assistant a long-term memory — for projects you're working on, journal entries, and the people in your life.

## What you get

- A persistent memory layer that survives across conversations
- Per-project notes so your assistant remembers the context, conventions, and active work for each project you touch
- A daily journal your assistant can write to and read back later
- People profiles — names, context, preferences, and important details — organized by how close you are
- Built-in privacy controls so you decide what's worth remembering

## When to use it

Turn this on if you want your assistant to actually know you — to recall what you've been working on this week, remember your friend's partner's name, or pick up a project right where you left it months ago. Best paired with assistants you talk to often.
