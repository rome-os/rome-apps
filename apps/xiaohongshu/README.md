# 小红书

用你自己已经登录的账号，把小红书的浏览、互动和发布都接进 Rome 的工作流里——不用切到 App、不用复制粘贴。

## 你能得到什么

- 浏览首页推荐、搜索笔记，按筛选条件找内容
- 查看笔记详情和评论，研究博主主页和过往作品
- 给笔记点赞、收藏，发评论、回复评论
- 一站式发图文笔记和视频笔记，也可以先填好草稿稍后再发
- 支持长图文的模板选择和分步编辑
- 全程使用你自己的登录态，看到的就是你账号里的真实视图

## 什么时候你会用到它

适合做小红书内容运营、博主选题研究、品牌投放调研，或者只是想让 AI 帮你打理日常发布和互动的人。把它接进工作流，搜素材、看评论、发笔记都不用反复在网页和 App 之间切换。
