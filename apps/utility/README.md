# Utility

Six Apache-2.0-licensed skills for visual design, frontend work, agent tooling, and browser testing.

## What you get

| Skill | Purpose |
| --- | --- |
| `canvas-design` | Create original posters, visual art, and other static designs |
| `frontend-design` | Build distinctive, production-grade frontend interfaces |
| `mcp-builder` | Design and implement Model Context Protocol servers |
| `skill-creator` | Create and improve reusable agent skills |
| `web-artifacts-builder` | Build complex, self-contained web artifacts |
| `webapp-testing` | Test local web applications with Playwright |

## When to use it

Install Utility when an agent needs to create a visual or interactive deliverable, build reusable agent tooling, or verify a web application in a real browser.
