# Settle

Get paid in favors for the help you've already given. Settle turns "I owe you one" into a polished request with a link you can send in seconds — and shows you exactly where each one stands.

## What you can do

- **Write a request in a few words** — what you did, who it was for, and how many favors it's worth.
- **Share one link** — Settle generates a private pay link and copies it for you.
- **Look professional** — the pay page introduces you with your photo, title and short bio, and reads like a clean invoice.
- **Get paid with favors** — the person you helped signs in with Rome Cloud and approves the exact amount before anything is charged.
- **Track progress** — see when each request was opened, when payment started, and when it was paid. You're notified the moment it lands.
- **Stay in control** — edit, withdraw, reopen, or mark a request paid when you were thanked some other way.

## When to use it

- You reviewed a deck, made an intro, or gave advice and want a simple way to be thanked.
- You did a small job for a friend or another founder and would rather not send a formal invoice.
- You want one place to see who has settled up and what's still outstanding.
