# Diff
A guardian-only, read-only Git review workspace in Rome. Review working changes, branches, PRs and arbitrary refs across allowlisted local repositories. Never stage, revert, commit, comment, or manage credentials. Keep polling, deep links, keyboard navigation and viewed persistence.

The composition follows a compact Changes pane, while Rome remains the visual authority: global language, semantic theme tokens, kit primitives, light and dark. Repository changes are user data and must not be edited.
