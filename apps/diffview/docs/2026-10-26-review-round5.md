# PR review follow-up, round 5 — 2026-10-26

v0.3.11 addresses three new findings against `d2e6b76`.

- **No recursive PR fetch:** explicitly pass `--recurse-submodules=no`. Repository/submodule `fetch.recurseSubmodules=on-demand` can otherwise fetch a missing gitlink commit inside an initialized submodule, moving non-app remote refs and writing that submodule's FETCH_HEAD despite the parent fetch's app-owned refspecs. A real bare-parent/bare-submodule fixture creates the PR and missing child commit in separate author repositories. It fails before the flag because the child's origin/main moves, and passes after the fix with child refs, HEAD, index bytes and FETCH_HEAD absence preserved. Parent ephemeral refs are cleaned too.
- **Warm conversation inventory:** reuse a bounded WeakMap inventory for one active scope and storage object. Scope/index/key-count changes, owned cross-document storage events and a failed write invalidate/rescan it. Only update the LRU index if its serialized order changes. An ordinary warm scroll flush does not enumerate origin keys or rewrite the index; it writes its new anchor once. Reads still read the touched value, legacy migration and quota pruning remain, and unrelated origin values are not read/deleted. The Browser storage listener has explicit unmount cleanup and ignores unrelated-key updates.
- **Version-correct file actions:** share the working-tree-right-side predicate between backend snapshot logic and the UI. Only All/Unstaged local work and ref-vs-worktree expose a local project-file link/action; staged, PR, commit, branch, Unpushed and ref-vs-HEAD do not pretend the checkout is the reviewed version. Deleted files remain unavailable. The public host event has the same guard; no new version-reading API or private host integration is introduced.

Tests include 100 warm scroll saves with 2,000 unrelated origin keys (zero key enumeration and zero index writes after warm-up), scope/revision/external-inventory invalidation, all prior storage budgets/quota tests, shared mode contracts, and a production file-menu matrix covering immutable/index versus working-tree comparisons. The old production bundle fails the new link-fidelity test. Existing scroll/worker/iframe/menu/tracking/fallback regressions remain enabled.

Final workspace type/test/browser totals, installed-runtime checks and CI are recorded in the PR and local validation artifact. No private SSH account, native macOS/Windows or long memory-soak acceptance is claimed. Draft remains; no merge or App Store publication.
