# Brainstorm

Turn a rough idea into a clear, approved design spec before any code gets written. Brainstorm acts as your thinking partner — it asks the right questions, weighs trade-offs with you, and walks away with a spec you actually want to build.

## What you get

- A guided conversation that pushes vague ideas toward concrete, shippable scope
- Clarifying questions one at a time, so you're never buried under a wall of "it depends"
- 2–3 viable approaches with honest trade-offs and a recommended path
- A structured spec covering purpose, constraints, success criteria, UX, error handling, and non-goals
- Early signal when an idea is too big for one spec, plus help breaking it down

## When to use it

Reach for Brainstorm whenever you have a new feature, refactor, or project that feels half-formed in your head. It's the step between "I want to build something for X" and writing the first line of code — ideal for design reviews, scoping sessions, and aligning with collaborators before implementation.
