# Facebook

Pull the list of people commenting on a Facebook page — directly from your logged-in browser session, no scraping setup required.

## What you get

- Extract commenters from any Facebook page feed you can see
- Uses your existing logged-in Facebook session, so you get the same view you'd see manually

## When to use it

Use this when you're researching engagement on a page, building a list of people who care about a topic, or feeding commenter data into a downstream workflow like outreach or audience analysis.
