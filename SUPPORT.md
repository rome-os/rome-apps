# Support

Choose the channel that matches what you need:

| Need | Where to go |
| --- | --- |
| Install or use Rome | [Rome documentation](https://romeos.cc/docs/rome) |
| Build a Rome App | [App development documentation](https://romeos.cc/docs/building-apps) |
| Ask the community | [Rome Discord](https://discord.gg/g7EFmEtmqc) |
| Report a reproducible app bug | [GitHub Issues](https://github.com/rome-os/rome-apps/issues) |
| Report a vulnerability | [Private vulnerability reporting](https://github.com/rome-os/rome-apps/security/advisories/new) |

When reporting a bug, include the app and version, your Rome version, reproduction steps, expected behavior, actual behavior, and relevant logs with secrets removed.

This repository tracks the source of first-party Rome Apps. Issues in the Rome runtime itself belong in [`rome-os/rome`](https://github.com/rome-os/rome/issues).
